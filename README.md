# Recall.run

A study app for keeping GPU systems, serving, training, and C++ in memory. It is a static site. Reviews, edits, and decks stay in this browser.

Open `index.html`, or use the GitHub Pages site. After one load it works offline, and the browser can install it.

- The daily queue uses FSRS. Grade Again, Hard, Good, or Easy (keys 1–4).
- Modes: free recall, flashcards, cloze, interview prompts, C++ recall, a mixed session, and a 5-minute drill.
- Add and edit cards in the library. Import JSON, Markdown, or CSV. Export a backup from Stats.

Old progress under the previous storage key is picked up once and left in place.
